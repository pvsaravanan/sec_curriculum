# SEC Curriculum Dashboard - Agent Notes

## Project Overview
Interactive progress dashboard for Saveetha Engineering College (SEC) UG Curriculum (Excel: `SEC - Learners -R19 & R24 - UG Curriculum - February 2025.xlsx`).

## Commands
- Run Next.js Dev Server: `npm run dev` (serves at http://localhost:3000)
- Build Next.js Production: `npm run build`
- Start Next.js Production: `npm run start` (serves at http://localhost:3000)
- Extract/Re-parse Excel data: `python extract_curriculum.py` (uses virtualenv at `venv/bin/python`)
- Parse Semester Marksheet PDF: `python parse_marksheet.py <path_to_pdf>`
